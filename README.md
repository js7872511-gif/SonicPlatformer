# Sonic Platformer (Geode)

A Geometry Dash 2.2081 Android64 Geode mod that draws an animated Sonic over the real player object while leaving the game's physics and QOLMod's Force Platformer controls intact.

## Features
- Animated Sonic idle / run / jump / fall / land frames
- SUPER / NORMAL mobile button
- Super Sonic form with gold aura and transform pulse
- Small capped speed boost while Super
- Does not create or replace the left/right platformer controls
- Designed for QOLMod → Force Platformer

## Target
- Geometry Dash 2.2081
- Geode 5.11.x
- Android64 / arm64-v8a

## Build

GitHub Actions automatically builds the Android64 `.geode` package on pushes to `main`.
